Privacy Policy

Last updated: October 24, 2026

Cassie Video Uploader ("the tool") uses YouTube API Services. By using the tool you are agreeing to be bound by the YouTube Terms of Service. Google's handling of your data is described in the Google Privacy Policy.

Who uses the tool

The tool is operated by and used only by its author, Yue Liang, to upload videos to the author's own YouTube channel. It is not offered to other users.

Information accessed

Through the YouTube Data API the tool accesses only what is needed to upload: the authenticated channel, and the videos, thumbnails and playlist entries that the tool itself creates. It does not read viewer data, comments, analytics, or any other account's data.

How information is used and stored

  • The OAuth access and refresh tokens are stored only in a local file on the author's computer (file permission 0600). They are never transmitted anywhere except to Google's own API endpoints.
  • Video files and metadata are read from the local disk and sent only to YouTube.
  • The tool does not use cookies, analytics, or tracking, and does not store any API data on any server.

Sharing

No information is shared with, sold to, or disclosed to any third party.

Revoking access and deleting data

Access can be revoked at any time at Google security settings. Deleting the local token file removes all stored API credentials; the tool keeps no other copies.
